# Locked In

A calm pomodoro focus app — a two-column dashboard where you pick a task, run focus sessions against it, watch progress accumulate as leaves, and keep an honest daily streak. Deep-work sanctuary: low-sensory, high-intent, profoundly calm.

Product requirements live in [`docs/prd.md`](docs/prd.md); the frozen design package in [`docs/design/`](docs/design/README.md).

## Stack

- **[Next.js 16](https://nextjs.org)** (App Router, Turbopack, Cache Components) + **React 19** — frontend on **Vercel**
- **[Convex](https://convex.dev)** — database, queries/mutations, auth, realtime sync (backend)
- **[HeroUI v3](https://heroui.com)** on **Tailwind v4** — components and theming (`data-theme` tokens)
- **[Zustand](https://github.com/pmndrs/zustand)** — client-only timer state (timestamp-anchored)
- **[Convex Auth](https://labs.convex.dev/auth)** — anonymous-first sessions, optional email magic link

## Architecture

```
app/            Next.js routes: / (dashboard), /stats, /login
components/     UI — every surface is a thin shell over lib/ or a Convex query
convex/         Backend: schema, queries/mutations, auth, HTTP routes
lib/            Pure logic — framework-free, unit-tested first
tests/          Vitest suites (unit + convex-test integration + DOM gates)
e2e/            Playwright flows against the production build
docs/           PRD, ADRs, frozen design package
```

Rules the codebase holds itself to (each is an ADR or plan decision, links below):

- **Pure logic lives in `lib/`** — pomodoro engine, streak, aggregations, CSV, merge, fractional ordering. Convex functions and React components are thin shells over it.
- **The timer is client-only** — Zustand, timestamp-anchored (`phaseEndsAt - now`), never a decrementing counter. Backgrounding the tab cannot drift it.
- **Every Convex function resolves its owner through one helper** (`convex/lib/owner.ts`) — no client-supplied owner ids anywhere.
- **Sessions are an append-only log** — streak, leaf counts, daily totals and all stats are derived at read time, never stored. CSV import is the only repair path.
- **Anonymous-first** — first load creates an identity with zero prompts; the magic link is an optional upgrade, and signing in asks before merging device data.

## Environment

**Frontend** (`.env.local`, written by `npx convex dev`):

| Variable | Purpose |
|---|---|
| `CONVEX_DEPLOYMENT` | Which Convex deployment `npx convex dev` pushes to |
| `NEXT_PUBLIC_CONVEX_URL` | Client query/mutation endpoint |
| `NEXT_PUBLIC_CONVEX_SITE_URL` | Auth HTTP routes (well-known/JWKS) |

**Convex deployment env** (`npx convex env set <NAME> <VALUE>` — never committed):

| Variable | Purpose |
|---|---|
| `JWT_PRIVATE_KEY` / `JWKS` / `JWT_PUBLIC_KEY` | Token signing (generated by `npx @convex-dev/auth init`) |
| `SITE_URL` | Where magic links point — your deployed frontend origin |
| `AUTH_RESEND_KEY` | Resend API key for magic-link email |
| `AUTH_EMAIL_FROM` | Optional sender address (defaults to Resend's onboarding sender, which only delivers to your own account email) |

Set each for **both** the dev and prod deployments (`--prod`); they are per-deployment, not global.

## Deploy

1. **Backend:** `npx convex deploy` (prod) — pushes schema, indexes and functions.
2. **Frontend:** `npx vercel --prod` — Vercel builds and serves `app/`.
3. Point `SITE_URL` at the Vercel URL so magic links return to the app.

Live: [locked-in-drab.vercel.app](https://locked-in-drab.vercel.app) (Convex Cloud backend).
